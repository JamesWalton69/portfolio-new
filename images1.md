# Portfolio image prompts

Generate one image for each prompt below. Save the finished files using the exact filenames listed; send them back or place them in `public/images/` and I’ll wire them into the site.

## Shared art direction

These are image assets for a personal portfolio for a full-stack and AI engineer. Make them feel like original, art-directed project artwork: tactile, bold, editorial, a little surreal, and polished enough for a design-led portfolio. Use confident color fields, thoughtful lighting, restrained texture or print grain, and one clear visual idea per image. The site chrome supplies project names and captions, so **do not include any text, lettering, logos, watermarks, UI mockups, browser frames, or fake screenshots**. Keep the main subject near the center with breathing room around it so the image can be cropped into both a near-square project tile and a wider case-study cover. Create a still image, not an animation.

**Suggested output:** 4:3 landscape, at least 1600 × 1200 px, PNG or high-quality WebP, sRGB.

## 1. Hitodama — `hitodama.png`

Create a distinctive editorial artwork for **Hitodama**, a gentle desktop companion that lives in a small floating island and can listen, speak, and control a computer. Center a tiny, living flame-spirit made of warm peach, pink, and ember-orange light inside a sleek, minimal floating glass capsule; a few delicate sakura petals orbit it. Suggest a dark desktop through a deep plum/ink background and subtle reflections, but keep the spirit bright, friendly, and immediately readable. The composition should feel like a premium piece of speculative product art, not a game character render or an actual software screenshot. Use a soft halo, restrained grain, generous negative space, and a strong silhouette. No words, interface elements, or extra characters.

**Color cue:** signature pink, peach, ember orange, deep ink.
